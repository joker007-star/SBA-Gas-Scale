# ESP-32-Fingerprint
to record attendance using fingerprint scanner 

This PlatformIO project is structured for the ESP32 using the Arduino framework. It integrates the SFM-V1.7 fingerprint sensor (UART), a 20×4 LCD (I2C), and a MicroSD card (SPI).

## Configuration
The project is configured using PlatformIO (`platformio.ini`) with the `esp32dev` board.

Dependencies:
- Adafruit Fingerprint Sensor Library
- LiquidCrystal_I2C
- SD
